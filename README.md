## 🎯 Overview

Compare your tattoo and piercing prices against market benchmarks across UK, US, EU, and Australia. See if you're under, at, or above market rate.

**Category:** Studio Operations

This is a free, open-source widget from the [Poli International Widget Suite](https://poliinternational.com/tools/) - a collection of practical tools for tattoo and piercing studios, artists, and clients. It runs entirely in the browser; no data is sent to a server.

---

## ✨ Features

- ✅ **Tattoo Studio Pricing**
- ✅ **How Much To Charge For Tattooing**
- ✅ **Piercing Prices Benchmark**
- ✅ **Tattoo Artist Rates UK**
- ✅ **Body Piercing Pricing Guide**
- ✅ **Studio Pricing Calculator**
- ✅ **Responsive Design** - works on desktop, tablet, and mobile.
- ✅ **Free & Open Source** - MIT licensed.

## 🚀 Installation

### Option 1: Use Online (Recommended)

No installation needed! Just visit:
**[https://poliinternational.com/tools/studio-pricing-benchmark/](https://poliinternational.com/tools/studio-pricing-benchmark/)**

### Option 2: Run Locally

This tool is pure HTML/CSS/JS - no build step. Clone the repo and open `index.html`:

```bash
git clone https://github.com/Poli-International/studio-pricing-benchmark.git
cd studio-pricing-benchmark
# open index.html in your browser
```
